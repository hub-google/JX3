# 給開發者的實機測試回報格式

**先附檔：** 將 `diagnostics/` 最新的 `jx3-diagnostic-*.json` 上傳聊天室。請先確認檔案沒有私人帳號、個資、記憶體傾印。

```text
程式版本：v0.1.2
Windows 版本：Windows 10/11，x64
Python：版本與 64-bit 資訊（診斷檔已有）
遊戲版本：官方客戶端可見的版本號／更新日期（不含帳號）
執行模式：離線測試 / 遊戲唯讀測試
測試 1（一鍵診斷）：PASS / FAIL / SKIP
測試 2（離線視窗）：正常 / 有錯誤（描述）
測試 3（唯讀客戶端）：成功解析 / 無程序 / 存取遭拒 / 偏移錯誤 / 無法判定
測試 4（場景比對）：
    場景 A：角色/NPC  正確 __ / 抽樣 __；物資 正確 __ / 抽樣 __
    場景 B：角色/NPC  正確 __ / 抽樣 __；物資 正確 __ / 抽樣 __
    場景 C：角色/NPC  正確 __ / 抽樣 __；物資 正確 __ / 抽樣 __
   距離偏差（如已比對）：__ 米（請註明量測方式）
測試 5（連續觀察）：__ 分鐘；CPU 約 __%；工具當機 __ 次；遊戲當機 __ 次
是否出現官方保護／警告／反作弊：沒有 / 有（描述現象，不貼私人紀錄）
首次出錯時所在階段：__
錯誤訊息或螢幕截圖：（記得遮住帳號、其他玩家資訊）
```

**禁止用這輪測試驗證寫入目標或技能連招**。只有讀取測試通過，也不表示反作弊無風險。若遇阻擋、遊戲崩潰或帳號提示，立即停止，不進行規避。
